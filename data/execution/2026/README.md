# 2026 county-seat budget execution

This directory is a reproducible corpus of official Forexebug Excel reports for
Romania's 41 county-seat municipalities plus Bucharest.

Every workbook is the Ministry of Finance report `FXB-EXB-901`, **budget
execution aggregated at principal credit-authorizer level**. The corpus includes
the completed quarters available on the source-audit date (24 August 2026):

- Q1, dated 31 March 2026;
- Q2, dated 30 June 2026.

The values are cumulative from 1 January through the reporting date. These are
public reports generated by Forexebug, not the signed set of quarterly
financial-statement annexes submitted by each municipality.

## Layout

```text
data/execution/2026/
  q1/                         # Q1 manifest, sources and verification
  q2/                         # Q2 manifest, sources and verification
  <county-code>-<county-slug>/
    <capital-siruta>-<capital-slug>/
      q1/forexebug_execution.xlsx
      q2/forexebug_execution.xlsx
```

Ilfov is the legal exception: its county seat is Bucharest. Entries 25 and 42
therefore contain the same official Bucharest workbook, while remaining separate
to preserve the repository's 42-code corpus convention.

## Populate or refresh

Python 3 and `curl` are the only requirements. Q2 is the default because it is
the latest completed quarter in this corpus:

```bash
python3 data/execution/2026/download.py
python3 data/execution/2026/download.py --quarter 1
```

Useful options:

```bash
python3 data/execution/2026/download.py --quarter 2 --overwrite
python3 data/execution/2026/download.py --quarter 2 --only 01,13,42
python3 data/execution/2026/download.py --quarter 2 --jobs 4
```

The downloader validates that each file is an OOXML workbook and checks its
report title, quarter-end date, entity CIF, entity name and worksheet structure.
It writes `verification.json` and `checksums.sha256` in the selected quarter's
metadata directory after every run.

The workbooks are intentionally ignored by Git; manifests, downloader,
checksums, verification reports and source tables remain small and auditable.
